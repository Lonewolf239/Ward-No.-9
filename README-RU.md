**«ПАЛАТА №9»** — хардкорный хоррор на выживание от первого лица, сделанный одним разработчиком на чистом Python: без игрового движка и без сторонних ассетов — каждая модель, текстура и звук сгенерированы самим кодом. Вы приходите в себя в заброшенной психиатрической больнице, и чтобы выбраться, придётся уходить от существа, которое реагирует не только на происходящее на экране, но и на реальный звук с вашего микрофона.

Автор: **Lonewolf239**

## 🌟 Особенности

- **Ваш микрофон — часть уровня.** `MicListener` в реальном времени слушает окружающий шум: кашель, стук по столу или слишком громкий разговор рядом с укрытием монстр услышит точно так же, как игровой звук.
- **Существо, которое действительно думает.** Четыре поведенческих состояния (`Patrol`, `Investigate`, `Stalk`, `Hunt`), память об увиденном, приглушённый слух через стены и двери, взлом дверей и методичный обыск шкафчиков, когда монстр уверен, что вы рядом.
- **Рассудок под давлением.** Темнота и близость угрозы истощают рассудок, вызывая панические эффекты, учащённое сердцебиение и галлюцинации при критически низком уровне. Бег даёт скорость, но выносливость строго ограничена.
- **Полностью процедурное аудио.** Гул эмбиента, сердцебиение, шаги и звуки самого существа синтезируются из математических волн (синусоиды, фильтрованный шум) прямо во время игры — ни библиотек звуков, ни готовых записей.
- **Три непохожих друг на друга этажа**, связанных общим хабом: верхний этаж лечебницы (сбор предохранителей), подвал (поиск вентилей) и уличный двор (поиск кусачек) — у каждого свой генератор планировки, визуальный стиль и темп.
- **Редактор комнат прямо в игре.** Встроенный редактор позволяет создавать свои комнаты и зоны двора и отправлять их автору, не выходя из игры; одобренные работы могут попасть в будущие уровни.
- **Пять языков** из коробки: английский, русский, испанский, французский и немецкий.

## 🚀 Установка и запуск

Игра распространяется полностью готовой сборкой — устанавливать Python или какие-либо зависимости для игры не нужно.

1. Перейдите в раздел [Releases](../../releases) или на страницу [itch.io](https://lonewolf239.itch.io/ward-no-9).
2. Скачайте архив под вашу ОС (`Windows`, `macOS` или `Linux`).
3. Распакуйте архив в любую папку.
4. Запустите исполняемый файл `ward9`.

При запуске игра сама проверяет наличие новой версии на GitHub Releases и может скачать и установить обновление за вас.

> **Для разработчиков:**
> Чтобы запустить игру из исходников, понадобится Python 3.10+ и зависимости из `requirements.txt` (`pygame`, `numpy`, `moderngl`, `sounddevice`). После этого достаточно `python main.py`.

## 🎮 Управление

| Клавиша | Действие |
| :--- | :--- |
| **W, A, S, D** | Перемещение |
| **Shift** | Бег (тратит выносливость, очень громко) |
| **Ctrl** | Присесть (бесшумное перемещение, укрытие и подглядывание из-за угла) |
| **F** | Включить/выключить фонарик (тратит батарею, привлекает существо) |
| **E** | Взаимодействие (открыть дверь, спрятаться в шкафчик, подобрать предмет) |
| **Мышь** | Осмотр |
